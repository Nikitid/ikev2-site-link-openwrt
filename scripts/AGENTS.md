# Checks

`check.sh` runs everything: its own contract assertions, then `check-index.sh`
and the test scripts.

- Mutate every new check before trusting it. Break what it guards, watch it
  fail, restore. A check that has never failed is decoration.
- Assert the invariant, not the wording. Assertions pinned to a literal line
  have already broken here on pure reformatting.
- Add the check in the same change as the fix, and name the failure it would
  have caught in a comment.
- Keep them POSIX and offline: no network, no router, no clock.

`docs/INDEX.md` is generated by `gen-index.sh`; `check-index.sh` fails when the
committed copy has drifted. Both carry a `# template:` marker and are shared
with the sibling repositories - fix a bug in the template, not only here.
